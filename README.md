A simple project comparing Naive Bayes and k-NN for diabetes prediction using clinical data.

Description:
Implements two classifiers:
-Gaussian Naive Bayes
-k-Nearest Neighbors (k=3, 5, 11)
-Evaluates accuracy and confusion matrices
-Visualizes results using Seaborn/Matplotlib

Dataset:
-diabetes.csv
-Features: pregnancies, glucose, blood pressure, etc.
-Target: Outcome (1 = diabetes, 0 = no diabetes)

Requirements:
Python 3.x  
pandas  
scikit-learn  
seaborn  
matplotlib
